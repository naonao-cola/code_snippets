# deepseek ocr2 下载模型
## 1. 解除可能冲突的代理变量
unset HTTP_PROXY HTTPS_PROXY ALL_PROXY

## 2. 设置镜像站（命令后跟的 &> /dev/null 只是为了让输出更干净，不影响功能）
export HF_ENDPOINT=https://hf-mirror.com

## 3. 下载模型（这行命令会直接显示进度条）
python 部署使用的这个仓库模型,c++ 部署使用官方模型
huggingface-cli download unsloth/DeepSeek-OCR-2 --local-dir ./models/DeepSeek-OCR-2 --resume-download

## 4 其他问题
hf_transfer（Rust加速库）与镜像站 hf-mirror.com 有兼容性问题，或者你的网络触发了 IPv6 黑洞



## 5 安装cmake
有两个问题,可能需要安装以下库
sudo apt install libssl-dev
sudo apt-get install -y libgl-dev

## 安装llama.cpp

```bash
# 1. 检查 cuBLAS 库文件是否存在（你已经做了）
ls /usr/local/cuda-12.4/targets/x86_64-linux/lib/libcublas*

# 2. 检查库文件版本信息
strings /usr/local/cuda-12.4/targets/x86_64-linux/lib/libcublas.so.12 | grep "CUBLAS_VERSION"

# 3. 确认 CUDA 编译器可以找到 cuBLAS 头文件
echo '#include <cublas_v2.h>' | nvcc -I/usr/local/cuda-12.4/include -x c -E - 2>/dev/null && echo "✅ cuBLAS 头文件可用" || echo "❌ cuBLAS 头文件缺失"
```

```bash
# 1. 克隆仓库（如果还没做）
## deepseek-ocr-2 参考仓库 https://github.com/sfallah/llama.cpp/tree/sf/deepseek-ocr-2  这个仓库提的一个pr
## https://huggingface.co/sabafallah/DeepSeek-OCR-2-GGUF
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp

# 2. 创建构建目录
mkdir -p build && cd build

# 3. 配置 CMake（显式指定 CUDA 路径）
cmake .. \
    -DGGML_CUDA=ON \
    -DCMAKE_CUDA_ARCHITECTURES="80;86" \
    -DCMAKE_CUDA_COMPILER=/usr/local/cuda-12.4/bin/nvcc \
    -DCUDAToolkit_ROOT=/usr/local/cuda-12.4

# 4. 编译（使用所有 CPU 核心）
cmake --build . --config Release -j$(nproc)
```
